# M0 功能验证清单

> 2026-10-23 · 挨个验证用。标 💰 的要花几分到两毛钱,其余免费。
> 准备:一个终端 `npm run build && npm run start`,另开一个终端按条敲命令。

---

## 一、免费(用已缓存的西安/敦煌/平遥就能验)

- [ ] **1. 缓存回放**:POST 西安(综合沿革)→ 秒回,`task_created` 里 `cached:true`,`done` 里 `yuan:0`
  ```bash
  curl -s -N -X POST localhost:3000/api/research -H 'content-type: application/json' \
    -d '{"lat":34.26,"lng":108.94,"place":{"province":"陕西省","city":"西安市","county":"西安市"},"direction":"综合沿革"}'
  ```
- [ ] **2. 全量恢复**:把上面返回的 taskId 填进 → 拿到完整报告+来源+时间线
  ```bash
  curl -s localhost:3000/api/research/<任务号> | python3 -m json.tool | head -40
  ```
- [ ] **3. 短轮询**:终态任务 → `done:true` 且带全文;跑新任务时查 → `continuePolling:true, intervalMs:3000`
  ```bash
  curl -s localhost:3000/api/research/<任务号>/poll
  ```
- [ ] **4. 参数校验**:经度给 999 → 400 + `invalid_params`
  ```bash
  curl -s -X POST localhost:3000/api/research -H 'content-type: application/json' -d '{"lat":0,"lng":999,"place":{"province":"a","county":"b"},"direction":"综合沿革"}'
  ```
- [ ] **5. 不存在的任务** → 404 + `not_found`
  ```bash
  curl -s localhost:3000/api/research/nope
  ```
- [ ] **6. 结构化日志**:服务终端能看到一行一个 JSON;另开终端 `curl` 一个请求后回看新增行
- [ ] **7. 测试套件**:`npm test` → 91 个全绿
- [ ] **8. 占位首页**:浏览器开 `localhost:3000` → "史地 M0"

## 二、要花一点钱的(单次 ¥0.08 左右)💰

- [ ] **9. 完整研究流**:POST 一个没跑过的组合(如 平遥+综合沿革)→ 依次出现 task_created → progress(规划/检索/抓取/成文)→ search_hit ×2-6 → content 逐字流 → sources → done;全程 40-90 秒
- [ ] **10. 报告质量**(第 9 条的报告):
  - 建制沿革章节必须有
  - 引用 [n] 都在来源列表编号范围内
  - 来源标题干净(无 HTML 碎片/无半句话)
  - 来源网址无 `#1#1#1` 之类尾巴
  - 报告老老实实说"资料未涉及"而不是编
  ```bash
  curl -s localhost:3000/api/research/<任务号> | python3 -c "import json,sys;print(json.load(sys.stdin)['task']['report_md'])"
  ```
- [ ] **11. 资料稀缺降级** 💰:POST 一个真正的无名山沟(比如 lat 31.12 lng 102.73 马尔康之外的沟里,换个坐标)→ 状态 `scarce`、报告顶部有"资料稀缺"横幅、只有建制沿革+自然地理两节
- [ ] **12. 失败路径**:把 `.env` 里 key 改错一位 → 重启服务 → POST 新地点 → `error` 事件 `llm_all_failed` → 改回 key 重启(报告页 GET 会显示 failed+错误码)

## 三、可靠性(重启服务时顺手验)

- [ ] **13. 重启清扫**:起一个新任务,跑到一半 Ctrl+C 杀服务 → 重启 → `GET /:id` 看该任务已变 `failed / stale_task`(不会永远"进行中")
- [ ] **14. 优雅停机**:Ctrl+C 时服务端日志打印退出过程,再启不报库锁错误
- [ ] **15. 十分钟硬上限**:难当场验(要等 10 分钟),可跳过;机制是看门狗强停

## 四、跑分脚本

- [ ] **16. 限额跑分**:`npm run m0` → 只跑 ≤3 个新地点就停,提示剩哪些留到下次;已缓存的免费回放不占名额
- [ ] **17. 产出物**:`reports/<时间戳>/` 里每地点一个 .md + summary.csv(打开看 name/status/yuan/elapsedMs 列)
